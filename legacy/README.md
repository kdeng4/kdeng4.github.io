# Historical Jekyll source

`jekyll/` preserves the previous al-folio website, including its content, assets, configuration, docs, and workflows. It is reference material for the Astro migration and is not part of the active build. Follow the root README and AGENTS.md for current development.

The original al-folio attribution and documentation are retained here and in the root license. Old workflows stored here do not run in GitHub Actions. The archive is excluded from formatting, TypeScript checks, and Vercel source uploads.
