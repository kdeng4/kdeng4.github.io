Developed a full-featured **Android application** that helps users organize, edit, and monitor job applications from start to finish.

### Features

- Timeline view for tracking application status across multiple positions
- Create, edit, and delete application entries with rich metadata
- Local persistence using Android SQLite for offline-first data storage

### Development Process

- Followed a comprehensive software development lifecycle: requirements analysis, design, implementation, test planning, and documentation
- Built in a team of three as part of a graduate-level software engineering course

### Tools & Techniques

- **Language:** Java
- **IDE:** IntelliJ IDEA / Android Studio
- **Storage:** Android SQLite
- **Course:** Software Development Process (CS 6300), Georgia Tech
- **Period:** September – December 2023
